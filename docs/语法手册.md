# Screenplay Language（.sp 剧本语言）语法手册 v0.1

一种专为剧本创作与 AI 写作设计的**轻量标记语言**。文件扩展名 `.sp`（也兼容 `.screenplay`），UTF-8 编码，中英双语。

设计目标：

- 像 Markdown 一样**纯文本、零标签噪音**，AI 生成与人类书写都很稳定；
- 语法元素与标准剧本结构一一对应（场景、动作、角色、对话、括号、转场）；
- 作者**只管内容，不管排版**：空行、缩进、字体、字号、页边距全部由编译器按规范统一输出；
- 在 VSCode 中**左侧写、右侧实时渲染**，一键导出与正式剧本版式一致的 PDF。

---

## 1. 一分钟示例

```
---
title: 雨会停
author: Eden Xiao
contact: 18084992319
---

# EXT 01 城市街头 日

一个巷子，周奕身披仙袍，手拿宝剑，将魔鬼甲逼到墙角。

@周奕
邪祟，你残害百姓，罪不容诛。

@魔鬼甲
神君饶命！神君饶命！

（彭宇露出肉眼可见的失落表情）

--镜头缓慢向窗外移动，聚焦夜晚天空，然后又往下抬升，转场到酒吧外围。
```

## 2. 文件总体结构

```
┌──────────────────────────┐
│ （可选）文件头 front matter │  ← 标题页信息
│  --- 围栏包裹               │
├──────────────────────────┤
│  正文：若干“块”             │  ← 场景/动作/对话/括号/转场/分页
│  块之间以空行分隔            │
└──────────────────────────┘
```

- 正文由**块（block）**顺序构成；块之间用**一个或多个空行**分隔。
- 源文件里空行数量**不影响最终排版**：编译器统一按规范留白（块间空一行、场景标题前空两行）。
- 行内首尾的多余空格会被忽略；一个段落内的连续换行将被智能合并（行末是中文/中文标点时直接相连，英文时补一个空格）。

---

## 3. 文件头（标题页）

必须位于文件**最开头**，用两行 `---` 围栏包裹，内部是 `键: 值`：

```
---
title: 雨会停
author: Eden Xiao
contact: 18084992319
email: eden@example.com
date: 2026年10月
draft: 第四稿
---
```

| 键 | 含义 | 排版 |
|---|---|---|
| `title` | 剧本标题 | 华文中宋 / Courier New，28pt，倾斜，居中，单倍行距 |
| `author` | 作者姓名 | 宋体 / Courier New，14pt，居中，单倍行距 |
| `contact` | 联系方式（电话/微信等） | 宋体 / Courier New，14pt，居中，单倍行距 |
| `phone` | 同 contact 的别名 | 同上 |
| `email` | 邮箱 | 14pt，居中 |
| `date` | 日期 | 14pt，居中 |
| `draft` | 稿本信息 | 14pt，居中 |
| `autonumber` | 场景标题自动编号开关（默认开，`false` 关闭） | 不显示在标题页 |
| 其他自定义键 | 原样在标题页居中超额行 | 14pt，居中 |

文件头整体可选；存在时标题页固定为 PDF 第 1 页，正文从第 2 页开始。

## 4. 正文元素

### 4.1 场景标题（scene heading）

**显式写法（推荐，最稳妥）**：行首 `#` 加一个空格。

```
# EXT 城市街头 日
# INT 别墅谈话 夜
```

**自动识别**：行首是 `INT`、`EXT`、`EST`、`INT./EXT`、`EXT./INT`（后接空格、点号或连字符）时，即使不写 `#` 也会识别为场景标题。

**自动编号**：场景关键字后若没有写编号，编译器会按场景在文档中的出现顺序自动插入两位补零序号：

```
# EXT 城市街头 日     ->  EXT 01 城市街头 日
# INT 别墅谈话 夜     ->  INT 02 别墅谈话 夜
```

- 已手动写编号（关键字后紧跟数字，如 `# EXT 05 城市街头 日`）时保持原样、不重复编号；
- 不是以场景关键字开头的标题不插入编号；
- 可在文件头加 `autonumber: false` 关闭自动编号。

排版：宋体 / Courier New，11pt，两端对齐，无首行缩进；**场景标题前自动空两行**，后空一行。

### 4.2 动作段落（action）

任何不匹配其他标记的普通段落，即为动作段落。

```
周奕没有犹豫，一剑挥出。魔鬼顿时灰飞烟灭。
```

排版：宋体 / Courier New，10pt，两端对齐，无首行缩进；段落间空一行。

### 4.3 角色与对话（character + dialogue）

行首 `@` 表示角色名，**紧随其后的非空行**（直到空行或下一个标记）是该角色的对话：

```
@周奕
邪祟，你残害百姓，罪不容诛。
```

一个角色连续说多段：

```
@彭宇
周奕，你当年救我。
我多想报答你，可是你什么都不缺。
```

- 角色名：黑体 / Courier New，10pt，**居中**，无首行缩进，独占一行；
- 对话内容：宋体 / Courier New，10pt，左对齐，**左缩进 3 厘米、右缩进 2.7 厘米**（相对版心）；
- 角色名与对话之间**不留空行**；
- 不同角色的对话之间、对话与动作之间**自动空一行**。

### 4.4 括号（parenthetical，表演/动作提示）

整行被中文全角 `（）` 或英文半角 `()` 包裹：

```
（彭宇露出肉眼可见的失落表情）
（说完，两人出门，准备去酒吧）
```

排版：仿宋 / Courier New，10pt，**居中**，无首行缩进。

### 4.5 转场（transition）

行首以 `--` 开头：

```
--镜头缓慢向窗外移动，聚焦夜晚天空，然后又往下抬升，转场到酒吧外围。
```

排版：宋体 / Courier New，10pt，两端对齐，**首行缩进 2 字符**，标识性符号 `--` 保留在开头。

### 4.6 强制分页

行首连续三个或更多等号：

```
===
```

在当前位置强制另起一页（标题页之后默认自动分页，通常无需手动使用）。

## 5. 注释

仅供作者与 AI 备注，不会出现在 PDF 中。

```
// 这是单行注释，整行不渲染

/* 这是块注释，
   可以跨多行，也可以在行内： */ 周奕走出巷子。
```

- `//`：从 `//` 到行尾均为注释；
- `/* … */`：块注释，可跨行。

---

## 6. 行内格式

| 语法 | 效果 | 示例 |
|---|---|---|
| `**文字**` | 加粗 | `**重要**` |
| `*文字*` | 斜体 | `*心声*` |
| `__文字__` | 下划线 | `__强调__` |
| `\字符` | 转义，原样显示 | `\*` 显示为 `*` |

行内标记只在**同一行内**生效，不跨段。

---

## 7. 空白与排版规则（编译器自动完成）

| 规则 | 输出 |
|---|---|
| 动作 / 对话 / 括号 / 转场 之间 | 空 1 行 |
| 对话与场景标题、动作段落之间 | 空 1 行 |
| 角色名 → 其对话 | 不空白，紧邻 |
| 进入新场景（场景标题前） | 空 2 行 |
| 页面 | A4，上下边距 2.54cm，左右边距 3.81cm |
| 标题页 | 独立第 1 页 |
| 对话块、括号 | 尽量不被分页截断 |

因此源文件中只需用**一个空行**分隔块即可，无需手工数空行。

## 8. 完整语法速查表（EBNF）

```ebnf
document    = [frontmatter] { blankline | comment | block } ;
frontmatter = "---" newline { meta-line } "---" newline ;
meta-line   = key ":" value newline ;
block       = scene
            | action
            | dialogue
            | parenthetical
            | transition
            | pagebreak ;

scene       = ( "#" space text )
            | ("INT" | "EXT" | "EST" | "INT./EXT" | "EXT./INT") text ;
            (* 渲染时自动在关键字后补 "NN" 序号，除非该处已写数字；autonumber:false 可关闭 *)
dialogue    = "@" cue newline { text-line } ;          (* 到空行/下一个标记为止 *)
parenthetical = "(" text ")" | "（" text "）" ;        (* 整行包裹 *)
transition  = "--" text ;
pagebreak   = "===" { "=" } ;
action      = 任意非上述标记的段落 ;
comment     = "//" ... | "/*" ... "*/" ;
```

## 9. 给 AI 的生成约定（Prompt 提示）

当让 AI 直接产出 `.sp` 时，可附加如下约束：

1. 若提供了标题/作者/联系方式，先输出 `---` 文件头；
2. 每个场景前输出 `# ` + 场景关键字与标题，**不要手写编号**（如 `# EXT 地点 日`，编号由编译器自动生成）；
3. 每句角色台词前必须有独立的 `@角色名` 行；
4. 表演提示、情绪动作整行用 `（……）`；
5. 转场镜头行以 `--` 开头；
6. 块与块之间用一个空行分隔；不要输出 Markdown 表格、无序列表符号或解释性文字；
7. 注释用 `//`。

---

## 10. 错误与诊断

- 解析器**不报错中断**：无法识别的段落一律按动作段落渲染；
- `@` 后缺少角色名等问题会在 CLI `--check` 与编辑器中给出诊断行号；
- 命令行检查：

```bash
node cli.js 剧本.sp --check
```
