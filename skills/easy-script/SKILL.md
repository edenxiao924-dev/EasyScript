# Easy Script（.sp 剧本语言）

用纯文本写剧本：角色只管内容，场景编号、缩进、字体、字号、空行、页边距全部由编译器统一输出。

## 工作流（按顺序执行，不要跳步）

0. **一次性准备（仅在需要灰色斜体画面描述时）**：MONTAGE 画面描述需要宋体斜体字形，无头打印不会自动合成中文斜体。独立安装时运行 `python scripts/build_oblique_font.py`（需 `pip install fonttools brotli`，机器上要有宋体），输出 `assets/oblique/SimSun-Oblique.woff2`；若本 Skill 放在仓库内，改运行仓库的 `python tools/build_oblique_font.py`（输出 `assets/fonts/`，供 `src/` 引擎加载）。不运行也能出 PDF，只是蒙太奇画面描述变为正体宋体。
1. **落实要素**：标题、作者、联系方式（用户没给就留空或询问，不要编造电话/邮箱）。
2. **写 `.sp` 文件**：UTF-8，扩展名 `.sp`。完整语法见 `references/syntax.md`；拿不准时先抄 `assets/template.sp`。
3. **校验**：`node scripts/render.js <file.sp> --check`。退出码 2 表示有语法错误，必须修到退出码 0 再继续。
4. **渲染**：`node scripts/render.js <file.sp> -o <file.pdf>`。
5. **交付**：交付 PDF；同时保留 `.sp` 源文件，用户后续要用编辑器实时预览。

命令统一用 `node scripts/render.js`（脚本位于本 Skill 的 `scripts/`，路径按当前工作目录解析，建议传绝对路径）。

引擎位置：脚本会自动寻找编译引擎——先看 `scripts/` 同目录，再看仓库的 `src/`（本 Skill 放在 `skills/easy-script/` 时）。若把本 Skill 单独复制安装，请把仓库 `src/` 下的 `parser.js renderer.js compiler.js pdf.js` 一并复制到 `scripts/`，即可完全独立运行。

| 目的 | 命令 |
|---|---|
| 语法体检 | `node scripts/render.js x.sp --check` |
| 出 PDF | `node scripts/render.js x.sp -o x.pdf` |
| 只出 HTML（排版与 PDF 一致） | `node scripts/render.js x.sp --html x.html` |
| 机器可读结果 | 追加 `--json` |
| 浏览器不在默认路径 | 追加 `--browser "C:\...\msedge.exe"` |

## 语法速查

| 元素 | 写法 | 要点 |
|---|---|---|
| 文件头 | `---` 内 `title: / author: / contact: / email: / draft: / date:` | 可选；有则生成独立标题页（第 1 页） |
| 场景标题 | `# EXT-地点-时间-环境` 或 `# INT 地点 夜` | 编号自动生成，**禁止手写编号** |
| 动作 | 普通段落 | 一个段落写一件事 |
| 角色 | `@角色名` 独占一行 | 台词写在紧随其后的行 |
| 画外音 | `@角色名VO` | 渲染 `（V.O.）`，灰色 |
| 画外声 | `@角色名OS` | 渲染 `（O.S.）` |
| 同人接续 | `@角色名CO` | 渲染 `（CONT'D）` |
| 括号提示 | 整行 `（……）` | 仿宋居中，只放表演/动作提示 |
| 转场 | `--镜头……` / `--切至：` | 保留 `--` 前缀 |
| 音效 | `SFX 雷声轰鸣` | 下划线 |
| 修订 | `revise{原文 [新文]}` | 新文红色，右上角标注日期与修订序号 |
| 蒙太奇 | `MONTAGE{ … }` | 画面描述灰色斜体；内部可含 `@角色` 对话 |
| 分页 | `===` | 一般不用，标题页后自动分页 |
| 注释 | `//` 或 `/* */` | 不进 PDF |
| 行内强调 | `**粗**` `*斜*` `__下划线__` | 仅同一行内生效 |

## 硬规则

- **块与块之间只用一个空行**。空行数量不影响排版，不要手工敲空行去凑间距。
- **不写 Markdown**：不要 `##`、`-`、`1.`、表格、代码围栏；`#` 只用于场景标题，`--` 只用于转场。
- **场景标题不写编号**：`# EXT-出租屋-夜-雨` 编译为 `EXT 01 出租屋 夜 雨`；确需指定序号时才手写数字。
- **每个角色每次发言前都要有独立的 `@行`**；同一角色连续多句台词可以写在同一个 `@` 块内，逐行书写。
- **括号独占整行**，不能与台词同段；台词与括号分开写。
- 台词不加引号、不加「某某说」；说话人由 `@` 行承担。
- 一个文件从第一场写到最后一场，不要分多个文件再拼。

## 写作要点

- 动作段落：现在时、第三人称、只写镜头能拍到或能听到的内容；不写心理活动，心理用台词或括号外化。
- 一场戏 = 一个地点 + 一个时间；换地点/换时间就新起场景标题。
- 台词短，一句一行，口语化；避免解释设定的信息倾泻。
- 场景标题字段统一：`EXT/INT - 地点 - 时间(日/夜/晨/昏) - 环境(雨/雪/晴，可省)`。
- 蒙太奇用于无对白的快速剪辑段落，或同一主题的多镜头并列；块内每条画面描述单独一行。

## 出问题时

| 现象 | 处理 |
|---|---|
| `--check` 退出码 2 | 按报的行号改语法（多是 `@` 后缺角色名、`revise{`/`MONTAGE{` 缺 `}`） |
| 未找到浏览器 | 装 Edge/Chrome，或 `--browser <path>`；也可 `--html` 出 HTML 后交付 |
| PDF 中文变方框/字体不对 | 运行环境缺 Windows 中文字体（华文中宋/宋体/黑体/仿宋）；提示用户在 Windows 上运行 |
| 标题页没出现 | 文件头缺 `---` 结束围栏，或不在文件最开头 |
| 场景没编号 | 标题不以 `INT/EXT/EST` 开头，或文件头写了 `autonumber: false` |
