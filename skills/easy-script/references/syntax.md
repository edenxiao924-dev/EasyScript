## 1. 文件结构

```
（可选）文件头：两行 --- 围栏内的 key: value
正文：若干「块」，块与块之间用一个或多个空行分隔
```

- UTF-8 编码，扩展名 `.sp`。
- 源文件的空行数量不影响排版；编译器统一按规格留白。
- 同一段内的连续换行会被智能合并：上行以中文/中文标点结尾直接相连，否则补一个空格。

## 2. 文件头（标题页）

必须位于文件最开头：

```
---
title: 雨会停
author: Eden Xiao
contact: 18084992319
email: eden@example.com
date: 2026年10月
draft: 第四稿
autonumber: false
---
```

| 键 | 含义 |
|---|---|
| `title` | 标题（28pt，倾斜，居中） |
| `author` | 作者（14pt，居中） |
| `contact` / `phone` | 联系方式（14pt，居中） |
| `email` `date` `draft` | 同上，逐行居中 |
| `autonumber` | 场景自动编号开关，`false` 关闭 |
| 其他键 | 原样追加到标题页，14pt 居中 |

文件头可省略；存在时标题页固定为第 1 页，正文从第 2 页开始。

## 3. 正文元素

### 3.1 场景标题

三种写法等价：

```
# EXT 城市街头 日
# EXT-城市街头-日
EXT-城市街头-日
```

- `#` 后可写空格或 dash 字段；dash 字段在编译时转为空格。
- 行首为 `INT / EXT / EST / INT./EXT / EXT./INT`（后接空格、点或连字符）即自动识别，`#` 可省。
- **自动编号**：关键字后未写数字时，按出现顺序插入两位序号 `01、02…`；已手写数字则保持原样；`autonumber: false` 可关闭。
- 关键字之外的标题（如 `# 序幕`）不插入编号。

### 3.2 段落：动作 / 场面 / 特效 / 摄影机（AP / SP / SE / CE）

四类段落的**排版完全一致**（宋体 10pt、两端对齐、无首行缩进、段后空一行），区别只在语义标记，便于 AI 与后期定位：

| 标识 | 类型 | 用途 |
|---|---|---|
| `AP` | 动作段落 | 人物做什么、怎么移动、操作什么物件 |
| `SP` | 场面段落 | 环境、陈设、空间关系、光线与氛围 |
| `SE` | 特效段落 | 爆炸、血肉、火光、闪烁、雨雪、变形等视觉特效 |
| `CE` | 摄影机角度与剪辑说明 | 机位、景别、运镜、剪辑节奏（只写「怎么看」，不写剧情） |

两种写法都成立（`{` 可与标识同行，也可另起一行；只写一行也可以）：

```
AP
{
齐夏起身，沿墙走了一圈，手掌贴着墙面推了推。
}

SP
{
四面墙、屋顶和地板都画着横竖交错的线，把空间切成一个个方格；屋里没有门。
}

SE{桌面凹下一块，粉白色的东西向四周铺开。}

CE
{
俯拍全景。推近到座钟指针。切至齐夏的眼睛。
}
```

- 不带标识的普通段落**默认就是动作段落**，排版与 `AP{}` 一致，老语法完全兼容。
- 块内的多行会按「中文相接、西文补空格」的规则合并成一个段落。
- 段落正文里不要出现成对的 `{` `}`，会被当成块的结束标记。

### 3.3 角色与对话

`@角色名` 独占一行，其后的非空行（直到空行或下一个标记）为该角色台词：

```
@周奕
邪祟，你残害百姓，罪不容诛。

@魔鬼甲
神君饶命！神君饶命！
```

同一角色连续多句：

```
@彭宇
周奕，你当年救我。
我多想报答你，可是你什么都不缺。
```

后缀（紧贴角色名，无空格）：

| 后缀 | 渲染 | 样式 |
|---|---|---|
| `VO` | `周奕（V.O.）` | 画外音，角色名与台词整体灰色 |
| `OS` | `彭宇（O.S.）` | 画外声，正常黑色 |
| `CO` | `彭宇（CONT'D）` | 同人接续，正常黑色 |

英文角色名只在后缀为大写时才剥离（`ALICEVO` 会拆，`AliceVo` 不会）。

### 3.4 括号（表演提示）

整行被 `（）` 或 `()` 包裹，仿宋居中：

```
（彭宇露出肉眼可见的失落表情）
```

括号夹在 `@角色` 与台词之间（或两句台词之间）时，仍属于这段对话，不会切断台词：

```
@花臂男
（嗓子发哑，愣了几秒）
你……是谁？
```

### 3.5 转场

行首 `--`：

```
--镜头缓慢向窗外移动，聚焦夜晚天空，然后又往下抬升，转场到酒吧外围。
```

### 3.6 音效

```
SFX 雷声轰鸣
SFX: 风声
```

渲染为 `SFX: 雷声轰鸣`，整段下划线，`SFX:` 标签加粗。

### 3.7 修订

大括号写法（`{` 可以同行，也可以换行；新文方括号可以跨行）：

```
revise{原文，不渲染。[替换后的新内容，红色显示。]}

revise
{
原文，不渲染。
[
替换后的新内容，红色显示。
]
}

revise{没有方括号时整段都视为新内容。}
```

渲染：新内容红色；段落右上角以 8pt 浅灰色右对齐标注 `2026.10.29 #1`（日期为导出当天，序号按文档内修订块递增）。

### 3.8 蒙太奇

`MONTAGE` 与大括号同行或换行均可：

```
MONTAGE{
@周奕VO
我是周奕。一名被抛弃的仙神。
他一个人在很好的光里。桌上只有一只杯子。
@周奕VO
来人间三百年。
}
```

```
MONTAGE
{
@周奕VO
我是周奕。一名被抛弃的仙神。
他一个人在很好的光里。桌上只有一只杯子。
}
```

- 生成左对齐加粗标题 `MONTAGE 01:`（按文档内蒙太奇块递增）；
- 内部 `@行` + 紧随一行构成对话，其余每行都是画面描述（灰色斜体）。

块内规则：`@行` 的下一行是台词；再下一行若仍是普通行，则作为画面描述，不会继续并入台词。

### 3.9 强制分页

行首三个及以上等号：`===`

### 3.10 页面与对话保护

- 角色名与其台词、括号尽量不被分页截断。

## 4. 注释与行内格式

```
// 单行注释
/* 块注释，可跨行 */
```

| 语法 | 效果 |
|---|---|
| `**文字**` | 加粗 |
| `*文字*` | 斜体 |
| `__文字__` | 下划线 |
| `\*` | 转义，原样输出 |

行内标记只在同一行内生效。

## 5. 空行与排版规则

| 规则 | 输出 |
|---|---|
| 动作 / 场面 / 特效 / 摄影机 段落之间 | 空 1 行 |
| 动作 / 对话 / 括号 / 转场之间 | 空 1 行 |
| 对话与场景标题、动作段落之间 | 空 1 行 |
| 角色名 → 台词 | 不留空行 |
| 场景标题之前 | 空 2 行 |
| 页面 | A4，上下 2.54cm，左右 3.81cm |
| 标题页 | 独立第 1 页 |

源文件只需一个空行分隔块。

## 6. EBNF

```ebnf
document      = [frontmatter] { blankline | comment | block } ;
frontmatter   = "---" newline { meta-line } "---" newline ;
meta-line     = key ":" value newline ;
block         = scene | para | dialogue | parenthetical | transition
              | sfx | revise | montage | pagebreak ;
scene         = ("#" space scene-text) | ("INT"|"EXT"|"EST"|"INT./EXT"|"EXT./INT") scene-text ;
scene-text    = field { "-" field } | text ;        (* dash 渲染为空格；自动补 NN *)
para          = [ tag newline ] "{" { text-line } "}"    (* 标识与大括号可同行；块可分多行 *)
              | action ;
tag           = "AP" | "SP" | "SE" | "CE" ;        (* 动作 / 场面 / 特效 / 摄影机-剪辑 *)
dialogue      = "@" cue [ "VO" | "OS" | "CO" ] newline { text-line } ;
sfx           = "SFX" ( space | ":" ) text ;
revise        = "revise" [ newline ] "{" { text-line } [ "[" { text-line } "]" ] "}" ;
montage       = "MONTAGE" [ newline ] "{" { dialogue | para } "}" ;
parenthetical = "(" text ")" | "（" text "）" ;
transition    = "--" text ;
pagebreak     = "===" { "=" } ;
action        = 任意非上述标记的段落 ;
comment       = "//" ... | "/*" ... "*/" ;
```

## 7. 排版规格

| 元素 | 中文 | 英文 | 字号 | 对齐/缩进 |
|---|---|---|---|---|
| 标题 | 华文中宋 | Courier New | 28pt | 居中，倾斜，单倍行距 |
| 作者/联系方式 | 宋体 | Courier New | 14pt | 居中 |
| 场景标题 | 宋体（加粗） | Courier New | 11pt | 两端对齐，无首行缩进 |
| 动作 | 宋体 | Courier New | 10pt | 两端对齐，无首行缩进 |
| 场面 / 特效 / 摄影机-剪辑 | 宋体 | Courier New | 10pt | 与动作段落完全一致 |
| 角色名 | 黑体 | Courier New | 10pt | 居中，无首行缩进 |
| 台词 | 宋体 | Courier New | 10pt | 左对齐，左缩进 3cm，右缩进 2.7cm |
| 括号 | 仿宋 | Courier New | 10pt | 居中 |
| 转场 | 宋体 | Courier New | 10pt | 首行缩进 2 字符 |
| 音效 | 宋体 | Courier New | 10pt | 左缩进 0，右缩进 2.79cm，下划线 |
| 修订新文 | 宋体 | Courier New | 10pt | 红色，两端对齐 |
| 修订标注 | 宋体 | Courier New | 8pt | 右对齐，浅灰 `#A0A0A0` |
| 蒙太奇标题 | 宋体 | Courier New | 10pt | 左对齐，加粗 |
| 蒙太奇画面描述 | 宋体斜体 | Courier New | 10pt | 左对齐，灰色 `#808080` |

追加规则：动作段落中，**有台词的角色名第一次出现时加粗**（后续出现不再加粗）。

字体依赖（Windows 自带）：华文中宋 STZhongsong、宋体 SimSun、黑体 SimHei、仿宋 FangSong、Courier New。
非 Windows 环境依次回退到 Noto Serif CJK SC / Noto Sans CJK SC，字形相近但不等同，投稿定稿请在 Windows 上导出。

## 8. 诊断与容错

- 解析器不中断：无法识别的段落一律按动作段落渲染。
- 已知诊断：`@` 后缺角色名、`revise` / `MONTAGE` / `AP` / `SP` / `SE` / `CE` 缺结束 `}`、标识后缺少 `{`、文件头缺结束 `---`。
- 大括号可同行也可换行；块内正文不要出现成对的 `{` `}`。
- 检查：`node scripts/render.js x.sp --check`，错误输出到 stderr，退出码 2。

## 9. 完整示例

```
---
title: 雨会停
author: Eden Xiao
contact: 18084992319
---

# EXT-城市街头-日

SP
{
一条窄巷，墙面潮湿。巷口亮着一盏坏了一半的路灯。
}

AP
{
周奕身披仙袍，手拿宝剑，把魔鬼甲逼到墙角。
}

@周奕
邪祟，你残害百姓，罪不容诛。

@魔鬼甲
神君饶命！神君饶命！

CE
{
低角度仰拍周奕，推近到剑尖。
}

周奕没有犹豫，一剑挥出。魔鬼顿时灰飞烟灭。周奕走出巷子。转眼间样貌瞬间变成了一个20出头、青春洋溢的大学生。

# INT-别墅谈话-夜

@彭宇
听说你要离开了？

@周奕
嗯，三个月后，到时候我在这边的财产还麻烦你帮我处理。

（彭宇露出肉眼可见的失落表情）

SFX 雷声轰鸣

SE
{
窗外一道白光，把两个人的影子压在墙上。
}

revise
{
周奕只是拍了拍彭宇的肩膀。
[
周奕沉默片刻，轻轻拍了拍彭宇的肩膀，转身走向门口。
]
}

MONTAGE
{
@周奕VO
我是周奕。一名被抛弃的仙神。
他一个人在很好的光里。桌上只有一只杯子。
}

--镜头缓慢向窗外移动，聚焦夜晚天空，转场到酒吧外围。
```
