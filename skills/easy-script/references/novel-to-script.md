# 小说 → 剧本：转换方法与自查清单

一句话标准：**写下的每一句，都必须是摄影机能拍到的画面、演员能表演的动作。** 不是，就改写或删掉。

## 一、元素映射

| 小说里的东西 | 转成 .sp 元素 |
|---|---|
| 环境描写、陈设、空间关系、光线氛围 | `SP{ … }` 场面段落 |
| 人物的具体动作、位移、物件操作 | `AP{ … }` 动作段落（也可直接写普通段落） |
| 爆炸、血肉、火光、闪烁、雨雪、变形等视觉特效 | `SE{ … }` 特效段落 |
| 机位、景别、运镜、剪辑节奏、「特写/俯拍/切至」 | `CE{ … }` 摄影机角度与剪辑说明 |
| 引号里的对话 | `@角色名` + 紧随其后的台词行 |
| 「他心想」「她怀疑」「他在回忆」等内心活动 | 改写：变成可演的微动作 / 括号提示 / 台词 / 画面细节 |
| 声音（钟声、脚步、尖叫、雷） | `SFX 内容` |
| 人称转换、时间跳跃 | `--转场说明` 或新的场景标题 |
| 长段叙述性背景（历史、设定交代） | 压成 SP 或拆进对话；仍交代不完就删 |

## 二、转换流程

1. **切场**：按「一个地点 + 一个时间」把小说切成场，每场一个 `# INT/EXT-地点-时间`。同一地点但时间跳了（如「三小时后」），就新起一场。
2. **抽事件**：每场只保留「谁做了什么、谁说了什么」。删掉解释、评论、抒情、作者旁白。
3. **外化内心**：把心理描写逐句问「演员能演出来吗？」——能，就写成动作或括号；不能，就删，或交给台词说出口。
4. **拆句子**：长句拆成短句，一段只写一件事；一段里出现两个以上动作主体，就拆段。
5. **落元素**：按上表把内容放进 AP / SP / SE / CE / 对话 / 括号 / SFX / 转场。
6. **体检与出片**：`--check` 修到退出码 0，再出 PDF，按第三节逐条自查。

## 三、自查清单（逐条过稿）

1. **没有内心活动**：删掉「他想」「她感到」「他回忆起」。观众看不到、听不到的东西，在剧本里不存在。
2. **少用形容词副词**：写「他把杯子摔在桌上」，不写「他愤怒地把杯子狠狠地摔在桌上」。愤怒由演员演、由动作显。
3. **不用被动**：「乔被保罗带着走」→「保罗拽着乔走」。看到「被」字就检查。
4. **台词能说出口**：一句一行，口语，短。台词跨页不断裂（避免人物连着几页背诵思绪）。
5. **段落短**：一段一个动作，像清单，不像散文；段与段之间空一行，靠排版留白，不靠形容词。
6. **一场一地点一时间**：地点或时间一变，立刻新起场景标题。
7. **只保留必要背景**：交代设定能让画面自己说完的，就别说；说不完的，让角色在争执里说出来。
8. **格式**：扩展名 `.sp`、UTF-8、块间一个空行、不用 Markdown、场景标题不写编号。

## 四、改写对照

| 小说原文 | 剧本写法 |
|---|---|
| 他站在那儿，思考着这一切意味着什么。 | （他停在原地，视线在墙面上来回移，手指在桌沿敲了两下） |
| 房间里弥漫着诡异的气氛。 | `SP{ 钨丝灯忽明忽暗，桌面上一层灰，座钟指针停在十二点。 }` |
| 她被这声音吓得浑身发抖。 | `AP{ 她的肩膀抖了一下，手里的杯子落地。 }` + `SFX 杯子碎裂` |
| 时间仿佛静止了。 | `CE{ 固定机位，三秒不动；只有座钟的秒针在走。 }` |
| 一声闷响，头颅在桌面上撞碎。 | `SFX 闷响` + `SE{ 桌面凹下一块，粉白色的东西向四周铺开。 }` |
| 他心想：这里没有门，他们是怎么进来的？ | `AP{ 齐夏起身，沿墙走了一圈，手掌贴着墙面推了推。 }` + `@齐夏`（低声）`没有门。` |

## 五、常见错误

- 把小说整段抄进 `AP{}`：段落变成散文，拍摄时无从下手。先拆句。
- 用 `CE{}` 写剧情：机位和剪辑说明只写「怎么看」，不写「发生了什么」。
- 对话里塞设定：「如你所知，我们是三年前……」——改成冲突里的短句。
- 一场戏里跨了两个地点：拆场。
- 内心独白直接用 `VO` 大段念：除非它就是影片的表达方式，否则先尝试外化成动作。
